# Iconography

Íconos tomados del canvas (relleno, 24×24, `currentColor`). Tamaño por defecto en la UI: 20px.
`eye` / `eye-off` no están dibujados en el canvas (toggle del SSN) y siguen el mismo peso visual.
Para usarlos: átomo `Icon` (`Mobile/Atoms/Icon`).

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(96px, 1fr))', gap: '16px' }}>
  {ICON_NAMES.map((name) => {
    const icon = ICONS[name];
    const paint = icon.kind === 'fill' ? { fill: 'currentColor' } : { fill: 'none', stroke: 'currentColor', strokeWidth: 2, strokeLinecap: 'round', strokeLinejoin: 'round' };
    return (
      <div key={name} style={{ display: 'grid', justifyItems: 'center', gap: '6px', fontSize: '12px', color: 'var(--color-text-secondary)' }}>
        <svg viewBox="0 0 24 24" width="24" height="24" aria-hidden="true" style={{ color: 'var(--color-text-primary)' }}>
          <path d={icon.d} {...paint} />
        </svg>
        <code>{name}</code>
      </div>
    );
  })}
</div>
